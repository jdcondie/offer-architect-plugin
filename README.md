# Offer Architect Plugin

Six offer skills for founders, creators, and consultants. Built for the Claude Operating System course.

## What's inside

- `/icp-modeller` — Build a tiered Ideal Customer Profile matrix
- `/offer-architect` — Mechanism, proof, transformation, structure
- `/message-market-fit` — Pressure-test messaging against the market
- `/pricing-scanner` — Pricing psychology scan
- `/sales-letter` — Long-form sales letter from your offer
- `/launch-sequence` — 5-email launch sequence

## Install

In Claude Cowork (Desktop):

1. Settings → Customize → click "+" → Add Marketplace
2. Paste this URL:

```
https://github.com/jdcondie/offer-architect-plugin
```

3. Sync → Install
4. Open a Cowork chat. Type `/` to see the slash commands.
